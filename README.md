# DRIVUS (드라이버스)

### Pleos Connect 기반 차량용 SNS 앱

**팀명:** OE (오이)  
**앱 이름:** DRIVUS (드라이버스)

DRIVUS는 Pleos Connect 환경에서 사용할 수 있는 차량용 SNS 앱입니다.

친구의 주행 상태와 위치, 목적지를 확인하고 메시지와 콕 찌르기 기능을 통해 소통할 수 있습니다. 또한 주행 기록 공유, 주행거리 랭킹을 통한 경쟁, 미니게임 등 다양한 기능을 제공하여 운전자 간의 교류와 즐거운 주행 경험을 지원합니다.

---

## 1. 주요 기능

### 1. 프로필 및 공개범위 설정
- 닉네임, 한 줄 소개, 차종 등의 프로필 정보 표시 및 수정
- 위치, 주행 상태, 목적지, 친구 목록 등 13개 항목에 대한 공개범위 설정
- `SwitchCompat`을 이용한 항목별 ON/OFF 기능

### 2. 친구 목록 및 주행 상태 확인
- 10명의 친구 목록 표시
- 친구별 주행 중, 정차 중, 비운행 상태 확인
- 친구의 현재 위치, 목적지 및 예상 도착 시간 확인
- 친구 선택 시 상세 정보 확인
- 콕 찌르기 및 음성 메시지 기능

### 3. 주행 타임라인
- 최근 한 달간의 주행 기록을 지도에 표시
- 방문 장소를 지도 위에 마커로 표시
- Polyline을 이용한 이동 경로 시각화
- 친구별 주행 기록 확인

### 4. 주행거리 및 랭킹
- 개인별 누적 주행거리 확인
- 친구 간 주행거리 비교 및 순위 표시
- 주간 및 월간 주행거리 랭킹 제공
- 주행거리를 기반으로 한 친구 간 경쟁 기능

### 5. 채팅
- 친구별 1:1 채팅 기능
- 대화 내용 및 최근 메시지 미리보기
- 이름 또는 대화 내용 검색
- 상대방의 주행 상태 및 차종 표시

### 6. 음성 메시지
- Pleos SpeechToText SDK를 이용한 음성 인식
- 차량 마이크 입력을 통한 음성 수신
- STT를 이용한 음성의 텍스트 변환
- 녹음 시간 및 오디오 파형 표시
- 음성 메시지 선택 및 전송

### 7. 미니게임
- 1:1 오목 대결
- 상식 퀴즈
- 드라이브 끝말잇기
- 친구에게 게임 대결 신청

### 8. 설정
- 계정 및 프로필 관리
- 알림 설정
- 주행 모드 설정
- 채팅 및 소통 설정
- 소리 및 음성 설정
- 미니게임 설정
- 화면 테마 설정 (다크 모드 / 라이트 모드)
- 차량 연동 설정
- 보안 및 계정 관리
- 앱 정보

## 2. 개발 및 테스트 환경

| 항목 | 환경 |
|---|---|
| 개발 도구 | Android Studio |
| 테스트 환경 | Pleos Connect v2.3.2 Emulator |
| Android 버전 | Android 14 (API 34) |
| 화면 해상도 | 1920 × 1080 (16:9) |
| 데이터베이스 | Firebase Firestore |

### 마이크 설정

에뮬레이터에서 음성 기능을 테스트하려면 다음 설정이 필요합니다.

1. 에뮬레이터 우측의 `...` 버튼 클릭
2. `Microphone` 메뉴 선택
3. `Virtual microphone uses host audio input` 활성화
4. PC 마이크를 통해 음성 입력 테스트

---

## 3. 실행 방법

1. 저장소를 다운로드하거나 `git clone`으로 복제합니다.
2. Android Studio에서 프로젝트 폴더 `oe`를 엽니다.
3. Gradle Sync를 진행합니다.
4. Pleos Connect v2.3.2 에뮬레이터를 실행합니다.
5. `Run 'app'` 또는 `app:installDebug`로 앱을 설치하고 실행합니다.
